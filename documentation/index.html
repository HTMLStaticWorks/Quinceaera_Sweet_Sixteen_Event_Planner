Luna & Lace Events Documentation

Thank you for purchasing Luna & Lace Events, a premium multi-page celebration planning and event design studio HTML5 template. Crafted specifically for Quinceañeras, Sweet Sixteens, and milestone galas.

Key Highlights
  • Built with clean HTML5, Bootstrap 5.3, CSS3, Vanilla JS, and GSAP 3.
  • Zero React, Vue, or heavy dependencies required. Fully standalone.
  • Instant Light & Dark theme toggle with localStorage persistence.
  • Filterable masonry portfolio with full-screen keyboard-navigable Lightbox.
  • Fully responsive across mobile, tablet, desktop, and large displays.

3. Light & Dark Themes

Theme switching is driven by the data-bs-theme attribute on the root <html> element. The state is remembered in the visitor's browser using localStorage.setItem('luna_lace_theme', 'dark').

All theme colors are governed by CSS Custom Properties in assets/css/style.css:

Light Theme Tokens:
--bg-primary: #FCF9F5;
--plum-primary: #380E2D;
--burgundy: #6E182F;
--gold-accent: #C5A059;
Dark Theme Tokens:
--bg-primary: #120914;
--bg-surface: #241429;
--gold-bright: #F5D992;
--text-primary: #FAF4FA;

4. Typography & Google Fonts

The template imports two high-fashion Google Font families:

  • Cormorant Garamond: Headings, display banners, and editorial quotes.
  • Plus Jakarta Sans & Outfit: Body copy, navigation, buttons, and form labels.

5. Components & Lightbox

The portfolio gallery includes dynamic vanilla JavaScript filtering and a lightbox modal. Add class="open-lightbox" and data-caption="..." to any link or button to launch the full-screen view. Pressing the Escape key or clicking outside will dismiss it automatically.

6. Forms & Validation

All forms utilize Bootstrap's native HTML5 constraint validation (class="needs-validation"). The Contact form on contact.html dynamically presents a celebration confirmation card upon completion.

Notice: As specified, this template is pure front-end HTML/CSS/JS. Forms contain client-side validation demonstrations and do not connect to a live backend database or dashboard portal.
