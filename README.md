# Luna & Lace Events — Quinceañera & Sweet Sixteen Luxury Event Planner

> **“Make the Moment Unforgettable.”**

A publication-grade, premium multi-page HTML5/Bootstrap 5/Vanilla JavaScript/GSAP website template designed for luxury Quinceañera, Sweet Sixteen, and milestone event planning studios.

Ready for deployment, client presentation, or commercial distribution on ThemeForest, TemplateMonster, and Creative Market.

---

## Key Features

* **Tech Stack**: HTML5, Bootstrap 5.3.3, CSS3, Vanilla JavaScript, GSAP 3.12.5, Bootstrap Icons. (Zero React/Vue/Angular dependencies).
* **21 Fully Developed Pages**: Complete multi-page architecture with zero dead `href="#"` links on important navigation.
* **Light / Dark Theme Switcher**: Instant theme toggle with `localStorage` persistence and `prefers-color-scheme` support.
* **Curated Visual Palette**: Warm ivory, champagne, deep plum, burgundy wine, dusty rose, soft blush, emerald teal, and restrained brushed gold.
* **Editorial & High-Fashion Layouts**: Includes two distinct homepages (Home 1: Classic Luxury Celebration Planner, Home 2: Fashion Editorial & Event Production focus).
* **Interactive Portfolio**: Masonry layout with category filtering and a full-screen, keyboard-navigable Lightbox modal.
* **Celebration Inquiries & Validation**: Front-end validated celebration inquiry form with celebratory feedback card.
* **Demo Authentication Screens**: Front-end Login, Sign Up, and Forgot Password UI demos (strictly no dashboard redirect, as specified).
* **Live Ticking Countdown**: Event gala countdown timer on `coming-soon.html`.
* **Complete Buyer Documentation**: Located in `documentation/index.html`.

## Getting Started

1. Open `index.html` in any modern web browser.
2. No build step or Node.js server required — all assets run directly off the local file system or any static web server (such as Live Server, Nginx, or GitHub Pages).
